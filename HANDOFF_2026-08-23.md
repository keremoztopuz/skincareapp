## İki tasarım kararı (yanlışlıkla bozulmasın)

1. **FFHQ kayıtları manifest'e `label="UNLABELLED"` yazıldı.** "50 yaşında, demek ki kırışık" demek confound'un kılık değiştirmiş hâlidir. Yaş **yalnızca sıralama anahtarı**, asla etiket:
   ```python
   def collect_ffhq() -> List[Dict[str, object]]:
       """FFHQ candidates for the Wrinkles / Healthy call, oldest first.

       Age decides the order, never the label. Sorting oldest-first puts the
       likely Wrinkles cases early so the reviewer finds them without hunting,
       but every image still has to be judged on whether wrinkles are visible —
       using the age band as the label is exactly the confound this avoids.
       """
       order = {"70_plus": 0, "50_69": 1, "40_49": 2, "30_39": 3, "20_29": 4}
   ```
2. **Karar verilmeyen görsel export edilmiyor.** Üç-yollu modda `ITEMS.filter(i => state[i.id])` — ziyaret edilmemiş bir yüz "varsayılan temiz" sayılmaz. `d` = atla bu yüzden var: belirsiz bir yüze karar vermeye zorlanmak etiket gürültüsünün girdiği yerdir. **Sessizlik bir etiket değildir.**
